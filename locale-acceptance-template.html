Runtime Locale Acceptance Worksheet

A language setting is a presentation decision. This worksheet helps a team prove that it does not accidentally replay a purchase, reward or objective action.

3. Run a bounded fixture

Hypothetical workshop fixture: the player opens an item with an approved Arabic/Latin mixed label, sees a price, starts a mission and receives a persistent objective. Capture wallet, mission ID and objective lifetime before using the supported language switch. After the switch, compare those values and the existing label. No purchase or reward is triggered in this fixture.

  1. Capture the current locale and state before the switch.
  2. Use the supported settings path; do not bypass normal navigation.
  3. Review the already-visible objective, not only a newly created label.
  4. Continue the route and check controls, state and expiry.
  5. Restart with the same save fixture and check the documented locale preference.

Also switch after an objective notice has expired. A refresh must not resurrect an obsolete message. Include a missing-string or unsupported-character fixture, but do not insert real player names or personal information into shared evidence.

4. Keep expected and observed separate

The CSV starts with every observation blank and every status pending. That is intentional: a sensible test description is not proof that the build passed. Fill the observed field with what actually happened and attach a build-specific screenshot, log or recording when useful. Record a failing case before changing the fixture or loosening the acceptance rule.

5. Decide the next work package

A failure in text rendering may need a font or layout change; a repeated gameplay event may need a state/presentation boundary fix. Keep those findings separate from a request for more translations. Return the approved corpus, updated source and reproduction route together so the next content update can repeat the checks.

For the wider commissioning boundary, see Arabic game localization: what to commission beyond translation. This worksheet is an original public planning resource, not a device test report or a claim that all locales have passed. Translation and linguistic review have their own named responsibilities.
